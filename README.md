# TalentFlow HR — Streamlit Prototype

A Python/Streamlit mock HR candidate review flow using fake data.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL Streamlit prints (usually http://localhost:8501).

## Included screens

- Hiring dashboard
- Candidate search/filter/sort
- Review queue
- Candidate detail/review
- Verification status
